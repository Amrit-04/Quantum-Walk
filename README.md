**QuMa** (Quantum Maze) is an experimental 2D puzzle game that introduces real quantum mechanical concepts—specifically **quantum entanglement**, **superposition**, and **quantum logic gates**—into classical maze generation and traversal using **IBM Qiskit**.

---

## ⚛️ The Quantum Concept

In a classical maze generated by **Eller's algorithm**, passages and walls are static: if you walk north through a passage, turning south will always bring you back to where you started.

In **QuMa**, maze walls are entangled using simulated quantum circuits via **IBM Qiskit**:
- **Quantum Random Generator (QRNG):** Maze topology is sculpted using measurements from a register of qubits in Hadamard equal superposition:
  $$H^{\otimes n}|0\rangle^{\otimes n} = \frac{1}{\sqrt{2^n}}\sum_{x=0}^{2^n-1} |x\rangle$$
- **Entangled Bell Pairs:** Interior wall pairs $(W_A, W_B)$ are prepared in the two-qubit Bell state:
  $$|\Psi^+\rangle = \frac{|01\rangle + |10\rangle}{\sqrt{2}}$$
- **Observer Wave-Function Collapse:** While in superposition ($\Psi$), walls glow and pulse. When the player approaches adjacent to an entangled wall, an **observer measurement** occurs! The two-qubit circuit is measured with Qiskit, instantaneously collapsing one wall into an open passage ($|0\rangle$) and the other into a solid barrier ($|1\rangle$).
- **Guaranteed Solvability:** The topological pairing guarantees that regardless of measurement outcome ($|01\rangle$ or $|10\rangle$), at least one valid path to the exit remains open!
- **Quantum Logic Gates:** Players can collect and execute quantum gates:
  - **`X` (Pauli-X Gate):** Bit-flip ($|0\rangle \leftrightarrow |1\rangle$). Inverts the states of the nearest wall pair, turning closed barriers into open doors!
  - **`H` (Hadamard Gate):** Re-superposes collapsed wall pairs back into $|\Psi^+\rangle$.
  - **`Z` (Pauli-Z Gate):** Applies phase flip ($|1\rangle \rightarrow -|1\rangle$).
  - **`S` (Phase-S Gate):** Applies a $\pi/2$ phase shift.

## 🎮 Gameplay & Controls

| Key | Action |
|:---:|:---|
| **Arrow Up / W** | Move Player Up |
| **Arrow Down / S** | Move Player Down |
| **Arrow Left / A** | Move Player Left |
| **Arrow Right / D** | Move Player Right |
| **X** | Activate Pauli-X Gate (Invert / Flip Nearest Wall Pair) |
| **H** | Activate Hadamard Gate (Re-Superpose Collapsed Wall) |
| **Z** | Activate Pauli-Z Gate |
| **S** | Activate Phase-S Gate |
| **R** | Generate & Launch New Quantum Maze |
| **ESC / Q** | Quit Game |

**Goal:** Navigate the player avatar (`player.bmp`) through the entangled maze corridors to locate the exit tile (`wall.bmp`) while adapting to dynamic quantum wall state changes.

## 🧩 Architecture & Components

```
Quantum-Walk/
├── main.py             # Pygame main loop, event handling, HUD sidebar, and rendering
├── Maze.py             # 2D maze grid representation and quantum gate distribution
├── MazeGenerator.py    # Eller's algorithm powered by Qiskit Quantum Randomness
├── Qrandom.py          # Quantum random number generator using AerSimulator / BasicSimulator
├── qmaze.py            # 2-qubit Bell circuit simulation and wave-function collapse logic
├── searchWall.py       # BFS pathfinding and topology-preserving entangled pair selection
├── requirements.txt    # Project dependencies (pygame, qiskit, qiskit-aer)
├── run.bat             # One-click Windows batch launcher
├── run.ps1             # PowerShell launcher
├── tests/              # Pytest automated test suite
└── *.bmp               # 8-bit retro pixel sprites (player, wall, block, gates)
```

## 🚀 Installation & Running

### 1. Clone the repository
```bash
git clone https://github.com/Amrit-04/Quantum-Walk.git
cd Quantum-Walk
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Launch the game
On Windows, you can double-click **`run.bat`** or run:
```bash
python main.py
```

### 4. Running the Tests
To run the automated test suite:
```bash
pytest tests/ -v
```
