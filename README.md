**QuMa** (Quantum Maze) is an experimental 2D puzzle game that introduces quantum mechanical concepts—specifically **quantum entanglement**—into classical maze generation and traversal.

---

## ⚛️ The Quantum Concept

In a classical maze generated by **Eller's algorithm**, passages and walls are static: if you walk north through a passage, turning south will always bring you back to where you started.

In **QuMa**, maze walls are entangled using simulated quantum circuits via **IBM Qiskit**:
- Wall pairs are initialized into an entangled two-qubit Bell state:
  $$|\Phi^+\rangle = \frac{|00\rangle + |11\rangle}{\sqrt{2}}$$
- When a player moves adjacent to or interacts with an entangled wall segment, the quantum state is measured and collapses.
- Because the walls are entangled, collapsing one wall instantaneously affects its entangled partner across the maze!
- **The Result:** Tracing back your steps does not guarantee a return to your original path. Players must navigate a shifting labyrinth where observation actively alters reality.

## 🎮 Gameplay & Controls

| Key | Action |
|:---:|:---|
| **Arrow Up / W** | Move Player Up |
| **Arrow Down / S** | Move Player Down |
| **Arrow Left / A** | Move Player Left |
| **Arrow Right / D** | Move Player Right |

**Goal:** Navigate the player avatar (`player.bmp`) through the entangled maze corridors to locate the exit tile while adapting to dynamic quantum wall state changes.

## 🧩 Architecture & Components

```
Quantum-Walk/
├── main.py             # Pygame main loop, event handling, and player rendering
├── Maze.py             # 2D maze grid state and tile drawing logic
├── MazeGenerator.py    # Eller's algorithm integrated with quantum random generation
├── Qrandom.py          # Quantum random number generation using Qiskit circuits
├── qmaze.py            # Quantum circuit definitions and entanglement logic
├── searchWall.py       # Wall pairing and adjacent boundary detection
├── requirements.txt    # Project dependencies (pygame, qiskit)
└── *.bmp               # 8-bit retro pixel sprites (player, wall, block, etc.)
```

## 🚀 Installation & Running

### 1. Clone the repository
```bash
git clone https://github.com/Amrit-04/Quantum-Walk.git
cd Quantum-Walk
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Launch the game
```bash
python main.py
```
